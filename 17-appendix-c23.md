# Приложение: возможности C23

Что из C23 можно применять уже сейчас и что пока нельзя. Всё в разделе «Что можно использовать сразу» поддерживают Clang 19, Clang 20 и GCC 14 (glibc 2.39); режим `-std=c23` принимают все три. Столбец «Глава» указывает, где возможность применяется; там же объяснено, зачем она нужна.

## Что можно использовать сразу

| Возможность | Зачем | Глава |
| --- | --- | --- |
| `nullptr` | Типобезопасный нулевой указатель, не путается с целым нулём | [типы и UB](02-types-and-ub.md) |
| `constexpr` для объектов | Константы времени компиляции вместо `#define` и перечислений-хаков | [интерфейсы](06-api-and-modules.md) |
| `typeof`, `auto` | Однократное вычисление аргументов в макросах, вывод типа | [контейнеры и макросы](09-containers-and-generics.md) |
| `bool`, `true`, `false`, `alignas`, `alignof`, `static_assert` как ключевые слова | Не нужны заголовки `<stdbool.h>` и `<stdalign.h>` | [память](03-memory-ownership.md), [типы](02-types-and-ub.md) |
| `thread_local` как ключевое слово | Не нужен заголовок `<threads.h>` для одного спецификатора | [потоки](10-concurrency.md) |
| `static_assert` без сообщения | Короткие проверки на этапе компиляции | [типы и UB](02-types-and-ub.md) |
| Пустой инициализатор `{}` | Нулевое состояние объекта для любого агрегата; основа правила «нулевое состояние допустимо» | [память](03-memory-ownership.md), [интерфейсы](06-api-and-modules.md) |
| Перечисление с фиксированным базовым типом | Размер и знаковость константы заданы явно | [интерфейсы](06-api-and-modules.md) |
| `[[nodiscard]]`, `[[maybe_unused]]`, `[[deprecated]]` | Диагностика игнорируемых результатов, неиспользуемых имён, устаревшего API | [интерфейсы](06-api-and-modules.md), [ошибки](04-errors-and-cleanup.md) |
| `unreachable()` из `<stddef.h>` | Подсказка оптимизатору; ошибочное предположение даёт неопределённое поведение, это не замена `assert` | [типы и UB](02-types-and-ub.md) |
| `<stdckdint.h>`: `ckd_add`, `ckd_sub`, `ckd_mul` | Проверка переполнения без неопределённого поведения | [типы и UB](02-types-and-ub.md), [память](03-memory-ownership.md) |
| `__VA_OPT__` | Макросы с необязательными аргументами | [контейнеры и макросы](09-containers-and-generics.md), [паттерны](14-patterns.md) |
| `<stdbit.h>`, `_BitInt`, `char8_t` | Битовые операции, целые заданной ширины, UTF-8 литералы | [типы и UB](02-types-and-ub.md) |
| `strdup`, `strndup` | Стали стандартными | [память](03-memory-ownership.md), [строки](05-strings-and-buffers.md) |
| Двоичные литералы, разделители цифр | Читаемые константы | [типы и UB](02-types-and-ub.md) |

Особенность `ckd_*` на Clang: он отвергает `char`, `bool` и перечисления как операнды и приёмник, GCC их принимает; используйте целые типы `int`, `unsigned`, `size_t` и подобные.

## Что работает не везде

| Возможность | Поддержка | Как поступать |
| --- | --- | --- |
| `#embed` | Clang 19 и 20; GCC 14 не знает | Только для Clang-сборок, либо генерируйте массив скриптом |
| `[[unsequenced]]`, `[[reproducible]]` | GCC 15; остальные пропускают с предупреждением | Проверяйте через `__has_c_attribute`; ложная пометка даёт неопределённое поведение |
| `memset_explicit`, `free_sized`, `free_aligned_sized` | В glibc 2.39 нет | Используйте `explicit_bzero` и обычный `free`; названия оставьте на будущее |
| `counted_by` (расширение GCC/Clang, не стандарт) | Clang 19 и 20; GCC 14 игнорирует | Включайте макросом по `__has_attribute(counted_by)` |
| `-fbounds-safety` (расширение Clang) | Не принимается Clang 19 и 20 | Для проверки границ используйте `counted_by` с `-fsanitize=array-bounds` и санитайзеры |
| `memcpy`, `memmove`, `memcmp` с `nullptr` при нулевой длине | Неопределённое поведение (и в C23, и раньше) | Проверяйте `len == 0` до вызова, подробности в главе [типы и UB](02-types-and-ub.md) |
| `realloc(p, 0)` при `p != nullptr` | Неопределённое поведение в C23; glibc освобождает блок и возвращает `nullptr` | Уменьшение до нуля пишите как `free(p)`, подробности в главе [память](03-memory-ownership.md) |
| Спецификатор `%b` в `printf` | Двоичный вывод; glibc 2.39 принимает; ASan в Clang печатает предупреждение | Используйте осторожно, подробности в главе [строки](05-strings-and-buffers.md) |

## Что появится в следующих версиях

Эти возможности вне C23 и вне базовой линии книги; рассматривайте их как направление, а не как инструмент сегодня.

- `defer` (технический стандарт): выполнение блока при выходе из области видимости; в Clang 22 включается флагом `-fdefer-ts`, в GCC пока нет. Это замена приёма `goto cleanup` из главы [ошибки и очистка](04-errors-and-cleanup.md).
- `_Countof`: безопасное число элементов массива вместо `sizeof a / sizeof a[0]`.
- Объявление переменной в условии `if` и `switch`, именованные циклы с `break` по метке.
- Определённое поведение `memcpy` и подобных при нулевой длине и `nullptr`.
