# Современный C: как читать книгу

Книга для опытного программиста, который уже знает C и пишет серверный код: базовые возможности языка не объясняются, разбираются приёмы, ловушки и решения, с которыми сталкиваются в реальной работе. Главы идут от основного к опциональному: первые семь формируют фундамент, остальные подключаются по мере необходимости. Практики объяснены по одной схеме: правило, причина, полный пример, подводные камни. Менее важное собрано в разделы «Коротко» и «Что ещё стоит знать».

## Базовая линия

Все примеры собираются как есть, блоки с `main` ещё и запускаются; блоки без `main` (фрагменты модулей, цель фаззера, плагин) только компилируются. Если пример использует что-то новее базовой линии, это указано в комментарии блока и в тексте.

- Стандарт: C23, флаг `-std=c23`.
- Компиляторы: Clang 19 и 20 (основной), GCC 14. Отладчик: LLDB 20 (основной), gdb в таблице соответствия команд.
- Платформа: Linux, glibc 2.39. Книга о языке и приёмах, а не об операционной системе: системное оформлено отдельной главой, переносимые решения предпочтены везде, где они есть.
- Сборка проверяется с предупреждениями `-Wall -Wextra -Wpedantic -Wconversion -Wshadow -Wformat=2 -Werror` и санитайзерами ASan и UBSan; потоковые примеры дополнительно под TSan на Clang. Блоки с расширениями GCC или Clang помечены и собираются без `-Wpedantic`.
- Примеры, которым нужна система сборки, сервер базы данных, каталог перевода или эмулятор другой архитектуры, проверены отдельными сценариями. Кросс-сборка проверена без санитайзеров, для Windows проверена только компиляция; для macOS, iOS и Android нужен SDK, и они только упомянуты.
- Примеры, которые демонстрируют ошибку, начинаются с комментария `/* Ошибка: ... */`; блоки, помеченные как неопределённое поведение, вызывают отчёт санитайзера. Неопределённое поведение, которое санитайзеры не ловят (aliasing, удалённая оптимизатором проверка, цикл ожидания, порядок вычисления), показано без отчёта и оговорено в тексте глав.

## Сквозные соглашения

Во всех главах используются одни и те же имена и правила, чтобы примеры читались как единое целое.

- Префикс модуля из двух-четырёх букв с подчёркиванием: `buf_`, `arena_`, `str_`. Типы-обёртки без суффикса `_t`.
- Жизненный цикл: `create`/`destroy` для объекта в куче, `init`/`clear` для структуры, размещённой где угодно; нулевое состояние структуры допустимо.
- Владение: у каждой аллокации один владелец, передача записана в контракте функции; `const` у указателя читается как «не владею».
- Ошибки: функция-команда возвращает `int` (0 или отрицательный код `-E...`), предикат возвращает `bool`, создающая функция возвращает `nullptr`, а если указатель `err` не `nullptr`, кладёт в него код результата (при ошибке `-E...`, при успехе 0 или ничего: это записано в контракте функции); параметр необязателен и ставится там, где код нужен вызывающему.
- Строки: срез `str` (указатель и длина) внутри программы, NUL-строки только на границе с библиотекой.
- Память: арена `arena` для данных одного времени жизни, макрос `NEW`.
- Интерфейс: таблица операций `ops` и `stream`, аллокатор как структура `allocator`.

## Как пользоваться

Для фундамента читайте подряд главы 01-07. Чтобы быстро найти ловушки по теме, смотрите подводные камни внутри практик. Для выбора библиотеки откройте приложение с каталогом. Для проверки, что нового в языке можно применять уже сегодня, откройте приложение про C23.
